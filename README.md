# ALU Higher Level Programming

This repository contains projects completed as part of the ALU Software Engineering program.

## Projects

- **python-hello_world** — Introduction to Python basics
- **python-if_else_loops_functions** — Conditionals, loops, and functions in Python
- **python-import_modules** — Working with Python modules
- **python-data_structures** — Python lists, tuples, and dictionaries
- **python-more_data_structures** — Advanced Python data structures
- **python-exceptions** — Exception handling in Python
- **python-classes** — Object-oriented programming in Python
- **javascript-warm_up** — Introduction to JavaScript fundamentals
